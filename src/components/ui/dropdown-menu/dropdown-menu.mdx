# DropdownMenu

Show a short list of secondary actions and navigation links from a caller-supplied trigger. Use Button with or without `href` when the action or destination should be directly visible in the page.

## Composition

DropdownMenu owns open state and composes the menu trigger with a popup. DropdownMenuPopup includes the portal and positioner; it fits its contents and defaults to side="bottom" and align="start". Both values can be set on the popup.

```tsx
import { Archive, BookOpen, Pencil } from "lucide-react";
import {
  Button,
  DropdownMenu,
  DropdownMenuItem,
  DropdownMenuLinkItem,
  DropdownMenuPopup,
  DropdownMenuTrigger,
} from "recipe-vault";

<DropdownMenu open={open} onOpenChange={setOpen}>
  <DropdownMenuTrigger render={<Button label="Actions" />} />
  <DropdownMenuPopup>
    <DropdownMenuItem icon={Pencil} onClick={onEdit}>
      Edit
    </DropdownMenuItem>
    <DropdownMenuItem disabled icon={Archive} onClick={onArchive}>
      Archive
    </DropdownMenuItem>
    <DropdownMenuLinkItem icon={BookOpen} href="/recipes">
      Browse recipes
    </DropdownMenuLinkItem>
  </DropdownMenuPopup>
</DropdownMenu>;
```

DropdownMenuItem represents an action and accepts the Base UI item props, including onClick and disabled. DropdownMenuLinkItem represents navigation; `href` uses the app's configured link renderer, or a native anchor without a provider. `render` overrides an individual link. Both accept an optional SVG component through `icon`, render it as a decorative leading visual, and close the menu when activated. Keep visible item text descriptive; it remains the accessible name.

Use a consistent icon treatment within each dropdown: either every menu item has a leading icon or none do. This applies across actions, links, and disabled rows.

The trigger stays in its active button style while the menu is open.

The popup and its text rows use the combobox popup's surface and spacing tokens. Keep each row's visible text concise and descriptive. A caller composing an icon-only trigger must provide its accessible name.

Base UI handles menu keyboard navigation and focus management. Open a menu with its trigger, move among rows with arrow keys, and close it with Escape.
