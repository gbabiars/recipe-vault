# Checkbox

## Purpose and choice

Represents independent yes/no choices. CheckboxInput is standalone; CheckboxGroup contains CheckboxGroupItem. Use RadioGroup when exactly one item from a set is chosen.

## Variants and composition

There is no visual variant prop. Standalone and group controls expose helpText, error, invalid, and visuallyHiddenLabel. Give each item a distinct value and concise label. A group has a shared label and a name for form submission.

## Content and accessibility

`CheckboxInput` adds a decorative `*` to its label when required. Its required state remains the accessible signal. Keep meaningful labels even when visually hidden. Explain errors in words and set required or disabled state to match behavior. `CheckboxGroup` legends and choice item labels stay unmarked.
