# Textarea

## Purpose and choice

Collects multi-line content such as recipe notes. Use TextInput for a short single-line value.

## Variants and composition

There is no visual variant. It accepts label, name, helpText, error, invalid, and visuallyHiddenLabel. Use a concrete label and optional help text. Controlled value and onValueChange are supported.

## Content and accessibility

When `required` is set, the label includes a decorative `*`; the native required state remains the accessible signal. A visually hidden label hides the marker with the label. Keep a real label even if hidden visually; explain errors and match required or disabled state to behavior.
