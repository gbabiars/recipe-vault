# Token usage

The token source is `src/app/globals.css`. Use semantic tokens for component
meaning; the light, dark, and system-dark definitions keep that meaning across
themes. This guide maps existing uses and does not add values.

`LayoutGap`, `LayoutAlign`, and `LayoutJustify` in `layout.ts` type the layout
props. A gap such as `gap="200"` resolves to `--space-200`. Use the component's
spacing props when available, and use semantic tokens in CSS modules for new
styles. See the [intent index](./README.md) for the component guidance.

Some motion durations and page-specific spacing and radius values remain
literal in the current CSS. Tokenization of those values is an open design task.
