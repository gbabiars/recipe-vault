# Avatar

## Purpose and choice

Represents a person with a profile image or initials in a circular avatar. Use
the person’s full name so the avatar can expose a useful accessible name.

## Variants and composition

`name` is required. An optional `imageUrl` displays the profile image. If the
URL is blank, absent, or the image fails to load, the avatar shows initials:
the first grapheme of a one-part name, or the first graphemes of the first and
last parts for names with multiple whitespace-separated parts. Middle parts
are skipped. Sizes are `small` (24 px), `medium` (32 px, the default), and
`large` (40 px).

```tsx
<Avatar name={userName} imageUrl={userImageUrl} size="medium" />
```

## Content and accessibility

For a nonblank name, the avatar has an image role and uses the normalized full
name as its accessible name whether the image or initials are visible. A blank
name shows a decorative Lucide User icon when there is no usable image and is
hidden from assistive technology. Caller `aria-label`, `aria-labelledby`,
`role`, and `aria-hidden` props can override these defaults.
