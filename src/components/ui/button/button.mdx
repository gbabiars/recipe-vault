# Button

Triggers an in-place action or submits a form. Use `ButtonLink` for navigation.

## Use and composition

- **Variants:** `default` is a neutral action, `primary` emphasizes an action, `subtle` reduces visual weight, and `danger` signals a destructive action. Sizes are `small`, `medium`, and `large`.
- **Composition and content:** Put a short verb-led label in the button. In a form, set `type="submit"`; outside a form, the default is `type="button"`. Use `Inline` to arrange related actions.
- **Caller accessibility:** Make the label describe the action, and reflect pending or unavailable states with `disabled` when appropriate. Explain a destructive action in its surrounding UI.
