# ButtonLink

## Purpose and choice

Navigates with button styling. Use Button for an in-place action.

## Variants and composition

Shares Button variants default, primary, subtle, danger and sizes small, medium, large. Provide an anchor href or a render element such as Next.js Link. Use a short destination label; PageHeader actions can hold the link.

## Content and accessibility

Keep link semantics and a meaningful destination.
