# Field

## Purpose and choice

Composes a labeled field when the ready-made controls do not fit. Use TextInput, Textarea, CheckboxInput, or RadioGroup when they fit.

## Variants and composition

Field layout is default or choice; other exported parts have no visual variant. Combine Field, FieldLabel, a Base UI field control, optional FieldDescription, and FieldError. Fieldset and FieldsetLegend name related fields; FieldItem wraps a choice.

## Content and accessibility

Give every control a label and useful error text. Keep controls connected through the Field context; use a legend for a related set. Built-in controls add a decorative required marker from their `required` state. A `FieldLabel` used directly for a custom field stays unmarked.
